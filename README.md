# MEW3 · app

App de janela da **MEW3 IA** para Mac, Windows e Linux. Aqui ficam só os instaladores.

**Baixar:** https://portal.mew3.com.br/ia/baixar (escolhe o arquivo certo para o seu computador)

| Sistema | Arquivo |
|---|---|
| Mac (Apple M1 a M4) | `MEW3-mac-arm64.dmg` |
| Mac (Intel) | `MEW3-mac-x64.dmg` |
| Windows 10/11 | `MEW3-windows-x64.exe` |
| Linux | `MEW3-linux-x64.AppImage` |

Depois de instalar, abra o app e clique em **Entrar com a MEW3**. Não tem conta? Crie em https://portal.mew3.com.br/ia/cadastro (US$ 3 de uso para começar).

Confira a integridade com o `SHA256SUMS.txt` de cada versão.

Prefere o terminal (planos Dev)? Veja https://www.mew3.com.br/ia#instalar
